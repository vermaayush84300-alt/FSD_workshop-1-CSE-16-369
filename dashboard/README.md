# Dashboard (React Router + Express)

Folders: `backend/` (API, port 5000) and `frontend/` (React, port 5173).

## Easiest: one command (from this folder)
    npm install      # installs root + backend + frontend packages
    npm run dev      # starts both servers

Windows: double-click `start.bat`.

## Or run separately
    cd backend  && npm install && npm run dev
    cd frontend && npm install && npm run dev   (second terminal)

Open http://localhost:5173
